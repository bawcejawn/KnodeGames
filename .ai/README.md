It contains NO application code. Nothing here is built, deployed or executed.

|---------------|---------------------------------------------------|
| platform/     | Platform-wide facts: what it is, how it's built, decisions, roadmap; the processes (session end, weekly review, free-prize switch); `reviews/` holds the weekly reviews |
| games/        | One file (or folder) per game                     |
| standards/    | Rules every game must follow, and how every AI chat starts (`AI_CHAT_STARTER.md`) |
| archive/      | History, not for daily reading: finished items (`DONE.md`), closed issues (`ISSUES_CLOSED.md`), and full copies of files from before each cleanup (dated folders) |
