# .ai — Knode Games Knowledge Base

This folder holds project knowledge for humans and AI assistants.
It contains NO application code. Nothing here is built, deployed or executed.

| Folder        | What lives here                                   |
|---------------|---------------------------------------------------|
| platform/     | Platform-wide facts: what it is, how it's built, decisions, roadmap |
| games/        | One file (or folder) per game                     |
| standards/    | Rules every game must follow                      |
| archive/      | Raw knowledge pulled from past chats, not yet sorted |

**Rule:** If two files disagree, `platform/DECISIONS.md` wins. Record the fix there.
**Placeholder format:** `{{TBD: description}}`
