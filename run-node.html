Run your own Koinos node

Start a Koinos mainnet node and block producer on your own computer. Each step says what it does, gives you the exact command to paste, and shows what you should see.

  • ~1 hourof your time, plus waiting
  • 150 GBfree disk space
  • 24/7a computer that stays on
  • $0software; you bring the VHP

Safe by design

  • This page never asks for a private key or recovery words. If anything does, stop.
  • It never sends your address or anything you type: your address only fills in the commands on your screen. (Page views are counted, without cookies.)
  • Your node makes its own key, which stays on your computer. Your KOIN and VHP stay in your wallet.
  • It runs the official Koinos node, at a version Knode Games has checked.

How to run a command

Every grey box is run the same way:

  1. Open PowerShell: click Start, type PowerShell, click Windows PowerShell.
  2. Open Terminal: press ⌘ Space, type Terminal, press Return.
  3. Open Terminal: press Ctrl+Alt+T.
  4. Click the yellow Copy button on the box.
  5. Click in the PowerShell window and right-click to paste.
  6. Click in the Terminal window and press ⌘V.
  7. Click in the Terminal window and press Ctrl+Shift+V.
  8. Press Enter. If you then see >>, press Enter once more.
  9. It's finished when the line you started with comes back (PS C:\…>ending in % or $). Compare what it printed with You should see.

Keep one window open or open a new one any time: each box goes to the right folder itself. Never paste commands from other websites or chats.

1

Check what you need

About 10 minutes

What this doesMakes sure your computer can run a node around the clock.

You need:

  • A computer that stays on 24/7: Windows 10 or 11 (64-bit), a Mac, or Linux.
  • 4+ processor cores and 16 GB of memory (8 GB at the very least).
  • About 150 GB free on a fast drive (SSD), on the drive Docker uses (usually C: on Windows).
  • Steady internet with no data cap, 25 Mbps down / 10 up or better. A cable beats Wi-Fi.
  • A Koinos wallet (Kondor on a computer, KOIN Vault on a phone) with some KOIN. Its address is your producer address. No wallet? Get one here.

Run this box (see How to run a command), then read how much space is free on your main drive.

Windows · PowerShell
Get-PSDrive C
Mac · Terminal
df -h /
Linux · Terminal
df -h /

Turn off sleep (a sleeping node misses its blocks):

  • Windows: Settings → System → Power → Screen and sleep → "When plugged in, put my device to sleep after": Never. Then Settings → Accounts → Sign-in options → turn on "Use my sign-in info to automatically finish setting up after an update", so the node comes back after updates.
  • Mac: System Settings → Energy (laptop: Battery → Options) → turn on "Prevent automatic sleeping when the display is off". Keep a laptop plugged in.
  • Linux: run sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target

Set the clock automatically. If it's off by even a minute, the node stops producing ("gossip disabled… halting block production"):

  • Windows: Settings → Time & language → Date & time → turn on Set time automatically, then press Sync now.
  • Mac: System Settings → General → Date & Time → turn on Set time and date automatically.
  • Linux: run sudo timedatectl set-ntp true; timedatectl should then say "System clock synchronized: yes".
Short on space? See what's using it (optional)

These boxes only look; they delete nothing. The usual big leftovers are old snapshot downloads (koinos-mainnet-….tar.gz, about 60 GB) and old node folders.

Run this box to list your 15 biggest folders. On a full drive it can take 10–20 minutes.

Windows · PowerShell
Get-PSDrive C
Get-ChildItem C:\ -Directory -Force -ErrorAction SilentlyContinue | ForEach-Object { $s = (Get-ChildItem $_.FullName -Recurse -File -Force -ErrorAction SilentlyContinue | Measure-Object Length -Sum).Sum; [pscustomobject]@{ Folder = $_.FullName; GB = [math]::Round($s / 1GB, 1) } } | Sort-Object GB -Descending | Select-Object -First 15
Mac and Linux · Terminal
df -h /
du -xh -d 1 ~ 2>/dev/null | sort -h | tail -15

Then run this box to find big leftover files (old snapshots, old Docker or virtual-machine disks).

Windows · PowerShell
Get-ChildItem C:\ -Recurse -File -Force -ErrorAction SilentlyContinue -Include *.tar.gz, *.vhdx | Where-Object Length -gt 2GB | Select-Object FullName, @{ n = 'GB'; e = { [math]::Round($_.Length / 1GB, 1) } }
Mac and Linux · Terminal
find ~ -xdev -type f \( -name '*.tar.gz' -o -name '*.raw' -o -name '*.vhdx' \) -size +2G -exec ls -lh {} \; 2>/dev/null

Know what a file is before you delete it. An old .tar.gz snapshot is safe to delete once unpacked. Keep the folders of a running node, and any holding a .env file or a block_producer folder (keys), unless you're sure. Windows: Settings → System → Storage → Cleanup recommendations safely clears temporary files.

You should seeYour drives. Free (Windows) or Avail (Mac/Linux) should show 150 GB (150G) or more.

If it doesn't work
  • Under 150 GB free? Use "Short on space?" above. Empty the Recycle Bin / Trash, uninstall unused programs, or move videos and photos to another drive. Windows can also keep Docker's data on another drive (step 2: Docker Desktop → Settings → Resources → Advanced → Disk image location).
  • Windows says the command isn't found? You opened Command Prompt; open Windows PowerShell instead.
  • A laptop works: keep it plugged in, lid open (or set the lid to "do nothing"), on a cable if you can.

Install Docker (and Git)

About 30 minutes (plus restarts)

What this doesInstalls Docker, the free program that runs the node, and Git, which downloads the Koinos node files. On Windows it also turns on WSL 2, which Docker runs on.

Windows

  1. Click Start, type PowerShell, right-click Windows PowerShell → Run as administrator → Yes.
  2. Paste the first box and press Enter. When it says so, restart your computer.
  3. Download Docker Desktop for Windows from docker.com and install it, keeping "Use WSL 2 instead of Hyper-V" ticked. Restart if asked.
  4. Open Docker Desktop and accept the terms (signing in is optional). Settings (gear) → General → tick "Start Docker Desktop when you sign in to your computer" → Apply.
  5. In a normal (not administrator) PowerShell window, paste the second box to install Git. Then close and reopen PowerShell.
  6. Paste the third box to check everything.
Windows · PowerShell (as administrator)
wsl --install --no-distribution
wsl --update
Windows · PowerShell
winget install --id Git.Git -e --source winget
Windows · PowerShell
docker version
docker compose version
git --version
docker run --rm hello-world

Mac

  1. Download Docker Desktop for Mac (Apple chip or Intel chip: Apple menu → About This Mac) from docker.com and drag it to Applications.
  2. Open Docker and accept the terms (signing in is optional).
  3. Docker → Settings: General → tick "Start Docker Desktop when you sign in" (Apple chip: also "Use Rosetta for x86_64/amd64 emulation on Apple Silicon"). Resources → Memory at least 8 GB, disk limit at least 200 GB. Apply & restart.
  4. Open Terminal and paste the box below. If your Mac offers the command line developer tools (Git), click Install, then paste the box again.
Mac · Terminal
docker version
docker compose version
git --version
docker run --rm hello-world

Linux

  1. Install Docker Engine: docs.docker.com/engine/install.
  2. Paste the first box (Git, Python and curl; Docker at start-up and without sudo), then log out and back in.
  3. Paste the second box to check everything.
Linux · Terminal (Ubuntu / Debian)
sudo apt-get update && sudo apt-get install -y git python3 curl
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
Linux · Terminal
docker version
docker compose version
git --version
docker run --rm hello-world

You should seeVersion numbers for Docker (with a Server part), Docker Compose and Git, then "Hello from Docker!".

If it doesn't work
  • "docker: command not found" or "cannot connect to the Docker daemon": open Docker Desktop, wait until the whale icon stops moving, try again.
  • Windows asks for a "UNIX username": that's an unneeded Ubuntu. Close the window; to remove it, run wsl --unregister Ubuntu.
  • Windows: Docker says WSL needs updating: in an administrator PowerShell run wsl --update, then wsl --shutdown, and reopen Docker Desktop.
  • Windows: "virtualization is not enabled": if Task Manager → Performance → CPU shows Virtualization: Disabled, turn it on in your BIOS/UEFI (search your PC maker + "enable virtualization").
  • Windows: "winget is not recognized": install App Installer from the Microsoft Store, or Git from git-scm.com with the defaults.
  • Linux: "permission denied" from Docker: log out and back in, then try again.

Download the weekly chain snapshot, check it, unpack it

Hands-on 10 minutes · waiting 2–8 hours

What this doesSaves days: instead of replaying the chain from block 1, your node starts from Armana's weekly snapshot (made Sundays around 04:00 UTC). The fingerprint (SHA-256) check proves the download is complete and exactly what Armana published.

4a. Find the newest snapshot

Run this box. It shows the newest snapshot, its size and fingerprint, and whether Armana's two fingerprints agree.

Windows · PowerShell
cd C:\koinos-node
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
$i = Invoke-RestMethod https://snapshots.armana.io/index.json
$s = $i.archives | Sort-Object { [int64]$_.height } -Descending | Select-Object -First 1
$old = $null; try { $old = (Get-Content snapshot.json -Raw -ErrorAction Stop | ConvertFrom-Json).name } catch { }
if ((Test-Path snapshot.tar.gz) -and ($old -ne $s.name)) { Remove-Item snapshot.tar.gz; "A newer snapshot is out: the half-finished older download was removed, so 4b starts fresh." }
$s | ConvertTo-Json -Depth 5 | Set-Content snapshot.json
$f = ((curl.exe -sL --ssl-no-revoke $s.sha256_url) -split '\s+')[0]
"Newest snapshot: $($s.name)"
"Size: {0:N1} GB" -f ($s.size_bytes / 1GB)
"Fingerprint: $($s.sha256)"
if ($f -eq $s.sha256) { "The list and its fingerprint file agree (both from Armana)" } else { "STOP: Armana's list and fingerprint file differ - do not use this snapshot" }
Mac and Linux · Terminal
cd ~/koinos-node
python3 - <<'EOF'
import json, os, urllib.request
i = json.load(urllib.request.urlopen("https://snapshots.armana.io/index.json"))
s = max(i["archives"], key=lambda a: int(a["height"]))
try:
    old = json.load(open("snapshot.json"))["name"]
except Exception:
    old = None
if os.path.exists("snapshot.tar.gz") and old != s["name"]:
    os.remove("snapshot.tar.gz")
    print("A newer snapshot is out: the half-finished older download was removed, so 4b starts fresh.")
json.dump(s, open("snapshot.json", "w"), indent=1)
f = urllib.request.urlopen(s["sha256_url"]).read().decode().split()[0]
print("Newest snapshot:", s["name"])
print("Size: %.1f GB" % (s["size_bytes"] / 2**30))
print("Fingerprint:", s["sha256"])
print("The list and its fingerprint file agree (both from Armana)" if f.lower() == s["sha256"].lower() else "STOP: Armana's list and fingerprint file differ - do not use this snapshot")
EOF

Extra careful: to check against a second source, compare the Fingerprint line with the one Armana posts in the Koinos Discord or Telegram, or another node runner's. If they differ, don't use it.

4b. Download it (the long part)

Run this box and leave the window open: 2–8 hours, depending on your internet. If the connection drops, it carries on by itself. It's done at DOWNLOAD COMPLETE.

Windows · PowerShell
cd C:\koinos-node
$s = Get-Content snapshot.json -Raw | ConvertFrom-Json
$size = [int64]$s.size_bytes
for ($try = 1; $try -le 200; $try++) {
  $have = 0; if (Test-Path snapshot.tar.gz) { $have = (Get-Item snapshot.tar.gz).Length }
  if ($have -eq $size) { "DOWNLOAD COMPLETE - go on to 4c"; break }
  if ($have -gt $size) { "STOP: the file is bigger than the snapshot. Delete snapshot.tar.gz, then do 4a and 4b again."; break }
  curl.exe -L --fail --ssl-no-revoke --retry 5 -C - -o snapshot.tar.gz $s.url
  if ($LASTEXITCODE -ne 0) { "The connection dropped (try $try of 200). Carrying on by itself in 30 seconds..."; Start-Sleep -Seconds 30 }
}
Mac and Linux · Terminal
cd ~/koinos-node
URL=$(python3 -c 'import json;print(json.load(open("snapshot.json"))["url"])')
SIZE=$(python3 -c 'import json;print(int(json.load(open("snapshot.json"))["size_bytes"]))')
for TRY in $(seq 1 200); do
  HAVE=$(python3 -c 'import os;print(os.path.getsize("snapshot.tar.gz") if os.path.exists("snapshot.tar.gz") else 0)')
  if [ "$HAVE" -eq "$SIZE" ]; then echo "DOWNLOAD COMPLETE - go on to 4c"; break; fi
  if [ "$HAVE" -gt "$SIZE" ]; then echo "STOP: the file is bigger than the snapshot. Delete snapshot.tar.gz, then do 4a and 4b again."; break; fi
  curl -L --fail --retry 5 -C - -o snapshot.tar.gz "$URL" || { echo "The connection dropped (try $TRY of 200). Carrying on by itself in 30 seconds..."; sleep 30; }
done

4c. Check the fingerprint

After DOWNLOAD COMPLETE, run this box. It works quietly for several minutes, then prints MATCH or NO MATCH.

Windows · PowerShell
cd C:\koinos-node
$s = $null
if (Test-Path snapshot.json) { $s = Get-Content snapshot.json -Raw | ConvertFrom-Json }
if (-not $s -or $s.sha256 -notmatch '^[0-9a-fA-F]{64}$') {
  "STOP - no snapshot.json yet: do 4a first"
} elseif (-not (Test-Path snapshot.tar.gz)) {
  "STOP - no snapshot.tar.gz yet: do 4b first"
} elseif ((Get-FileHash snapshot.tar.gz -Algorithm SHA256).Hash -eq $s.sha256) {
  "MATCH - the download is complete and unchanged"
} else {
  "NO MATCH - delete snapshot.tar.gz and download again"
}
Mac and Linux · Terminal
cd ~/koinos-node
EXP=$(python3 -c 'import json;print(json.load(open("snapshot.json"))["sha256"].lower())' 2>/dev/null)
if [ ${#EXP} -ne 64 ]; then echo "STOP - no snapshot.json yet: do 4a first"
elif [ ! -f snapshot.tar.gz ]; then echo "STOP - no snapshot.tar.gz yet: do 4b first"
else
  GOT=$( (sha256sum snapshot.tar.gz 2>/dev/null || shasum -a 256 snapshot.tar.gz) | cut -d' ' -f1)
  if [ "$EXP" = "$GOT" ]; then echo "MATCH - the download is complete and unchanged"; else echo "NO MATCH - delete snapshot.tar.gz and download again"; fi
fi

If it doesn't work
  • 4a says STOP: don't use that snapshot; try again in an hour. (Older Windows 10, "Could not create SSL/TLS secure channel": install Windows updates.)
  • 4b: "The connection dropped" now and then is normal. Window closed or PC restarted? Paste 4b again: it continues. If it stops with "404", that snapshot was retired: do 4a again (it clears the half-download), then 4b.
  • 4c says NO MATCH: delete the file (Remove-Item C:\koinos-node\snapshot.tar.gz or rm ~/koinos-node/snapshot.tar.gz), then redo 4a–4c.
  • 4d: "No space left on device": repairing (step 8)? Delete the old data first: docker run --rm --network none -v koinos-data:/k alpine:3.20@sha256:d9e853e87e55526f6b2917df91a2115c36dd7c696a35be12163d44e6e2a4b6bc rm -rf /k/chain-old /k/block_store-old. Start the node and wait until it's caught up

A few minutes · catching up: a few hours

What this doesStarts your node. It loads the snapshot, then fetches newer blocks from other nodes until it's level with the network.

5a. Start

Run this box. The first time, it downloads the node's programs (a few minutes).

Windows · PowerShell
cd C:\koinos-node\koinos

Remove-Item C:\koinos-node\heal-paused -ErrorAction SilentlyContinue
Mac and Linux · Terminal
cd ~/koinos-node/koinos

5b. Is it caught up?

Run this box now and every 15 minutes or so. It's caught up when Behind by is under 10.

Windows · PowerShell
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
$me = $null; $net = $null

7

Fill your producer wallet with VHP

About 10 minutes

What this doesGives your node its weight: the more VHP your producer address holds, the more blocks it produces. You make VHP by burning KOIN, 1 for 1.

  • How much? Any amount produces some blocks. We suggest about 10,000 VHP to start; Producer lookup shows what to expect.
  • Keep about 100 KOIN unburned: your wallet needs KOIN, and its Mana, to keep working (the Koinos docs warn against burning it all).
  • Get KOIN: Get KOIN and VHP (vKOIN and the Vortex bridge).
  • Burn KOIN into VHP: Burn KOIN, from your producer wallet.
  • Want KOIN back later? Swap VHP → KOIN in one step.
  • New VHP counts for production about a minute (20 blocks) after it arrives.

You should seeThe VHP in your wallet. Your address appears on Producer lookup after its first blocks (step 9).

If it doesn't work
  • Burned with the wrong wallet? VHP counts for the address holding it: send it to the producer wallet.
  • Unsure how much? Start small; you can burn more later. Burning can only be reversed by swapping VHP back on the Swap page.
8

Keep it live

1 minute a week

What this doesKeeps your node producing, and fixes the two common problems: a stuck node and a damaged one. These are the fixes Knode Games uses on its own nodes.

Already done for you

  • Crashed parts restart by themselves.
  • After a computer restart, Docker starts when you sign in (step 2) and starts the node.
  • The node's data sits in a Docker volume (step 3), not a shared folder, the most common cause of damaged data.

Turn on automatic self-heal (recommended)

A small script checks your node every 20 minutes. If it has frozen (far behind and not moving, or not answering), it restarts it: at most once per 50 minutes and 3 times in 6 hours, then it tells you. More about self-heal
  • It never starts a node you stopped with the stop box (step 10): it stays paused until you start it with 5a. The repair, stop and update boxes pause it while they work. Pressing Stop in Docker Desktop doesn't pause it: it starts the node again within about 40 minutes.
